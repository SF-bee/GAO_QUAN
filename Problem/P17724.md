# P17724 [SCP-S 2026] 路短最 / path

## 题目背景

## 题目描述

给定一张有 $n$ 个节点、$m$ 条边的无向简单连通图 $G=(V,E)$，节点编号为 $1,2,\ldots,n$，每条边的长度均为 $1$。$G$ 满足**一条边至多在一个简单环中**，也就是说它是一张**仙人掌图**。

我们在这张图上运行“Artskjid 算法”，计算从节点 $1$ 到各个节点的最短路长度。算法的流程如下：

1. 维护二元组集合 $S$、下标为 $1,2,\cdots,n$ 的数组 $d$ 与计数器 $C$。初始时 $S=\{(1,0)\}$，$C=0$，$d_1=0$，对于所有 $2\le i\le n$ 有 $d_{i}=+\infty$。
2. 找到 $S$ 中第二个元素**最大**的二元组，如有多个，取第一个元素最小的。设这个二元组为 $(u,\delta)$，将 $(u,\delta)$ 从 $S$ 中删去。
3. 若 $\delta\neq d_u$，返回步骤 2，否则将 $C$ 加上 $1$ 并继续。
4. 对于所有满足 $(u,v)\in E$ 的点 $v$，若 $d_v>d_u+1$，则将 $d_v$ 改为 $d_u+1$，并向 $S$ 中加入二元组 $(v,d_v)$。
5. 若 $S=\varnothing$，结束程序，否则返回步骤 2。

可以发现这个算法与经典的 Dijkstra 算法的区别只有取出二元组时要求第二个元素**最大**。
