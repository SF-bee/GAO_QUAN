# T817607 A. mex

## 题目描述

小 H 有的两个长度均为 $n$ 序列 $a_1,a_2,\dots,a_n$ 与 $b_1,b_2,\dots,b_n$。

对每个位置 $1\le i\le n$，她可以选择交换或不交换 $a_i$ 和 $b_i$。

请你帮可爱的小 H 计算：

1. 操作后序列 $\operatorname{mex}(a)$ 的最小值；
2. 达到该最小值的她可以进行的交换方案总数，答案对 $10^9+7$ 取模。

记 $S$ 为交换位置的集合，两个方案不同，当且仅当 $S_1\not= S_2$。

对于非负整数序列 $a_1,a_2,\dots,a_n$，定义 $\operatorname{mex}(a)$ 为序列 $a$ 中没有出现过的最小非负整数。如 $\operatorname{mex}(\{0,3,3,2\}) = 1$。

## 输入格式

第一行一个正整数 $n$，表示序列的长度。

第二行 $n$ 个非负整数 $a_1,a_2,\dots,a_n$。

第三行 $n$ 个非负整数 $b_1,b_2,\dots,b_n$。

## 输出格式

输出一行两个整数，用空格隔开。

第一个整数代表小 H 可以得到的最小 $\operatorname{mex}(a)$；

第二个整数代表达到该最小值的交换方案数目，对 $10^9+7$ 取模。

## 输入输出样例 #1

### 输入 #1

```text
2
0 1
0 3
```

### 输出 #1

```text
1 2
```

## 输入输出样例 #2

### 输入 #2

```text
3
0 1 5
0 3 4
```

### 输出 #2

```text
1 4
```

## 说明/提示

样例 $1$ 中，合法的两种方案为：$S_1=\{1,2\},S_2=\{2\}$。

样例 $2$ 中，为：$\{2\},\{2,3\},\{1,2\},\{1,2,3\}$。

对于所有测试数据，$1\le n\le 5\times 10^5,0\le a_i,b_i\le 10^9$。
