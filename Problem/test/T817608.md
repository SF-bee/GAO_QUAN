# T817608 B. triple

## 题目描述

小 H 有 $n=3k$ 个二元组 $(a_i,b_i)$，她保证 $a,b$ 均为一个排列，且 $1\le a_i,b_i\le n$。

小 H 还喜欢三元组，她想让你将这些二元组划分为 $k$ 个三元组。

小 H 喜欢美丽的划分，记一个三元组 $(i,j,l)$ 的**美丽值**为 $\max(|a_i-a_j|,|a_i-a_l|,|a_j-a_l|)+\max(|b_i-b_j|,|b_i-b_l|,|b_j-b_l|)$。

可爱的小 H 想要你构造出美丽值之和最大的划分。因为小 H 是个善良的女孩子，如果你只知道最大的美丽值，也可以获得部分的分数。

## 输入格式

第一行一个正整数 $n$。

接下来 $n$ 行每行 $2$ 个正整数 $a_i,b_i$。

## 输出格式

第一行输出最大的美丽度总和。

接下来 $k$ 行，每行输出三个互不相同的卡片编号 $i,j,l$，代表一组三元组。

## 输入输出样例 #1

### 输入 #1

```
3
1 1
2 2
3 3
```

### 输出 #1

```
4
1 2 3

```

## 输入输出样例 #2

### 输入 #2

```
6
4 4
5 2
2 6
6 3
1 5
3 1
```

### 输出 #2

```
16
5 1 2
3 6 4

```

### 输入 #3

```
9

7 1

```

```

9 8 6

```

## 说明/提示

对于全部数据，保证 $3|n,1\le n\le 10^6$，$a,b$ 均为排列。

如果你只会第一行的答案，可以获得一个测试点 $40\%$ 的分数，请确保你按照输出格式输出剩余 $n$ 行的内容。

::cute-table{tuack}

测试点编号|数据范围与特殊性质
----------|------------------
$1\sim 3$|$n \le 6$
$4\sim 7$|$n \le 15$
$8\sim 13$|$n \le 3000$
$14\sim 20$|$n \le 10^6$

另外，对于每类测试点的第一个测试点（$1,4,8,14$）保证 $a_i=b_i=i$。
