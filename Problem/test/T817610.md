# T817610 D. recall

## 题目背景

小 H 喜欢最优化，不喜欢计数，于是选择了这道最优化题……

## 题目描述

小 H 常常追忆过去。

小 H 有个回忆序列 $a$，她使用一个正整数代表一个回忆。

小 H 喜欢差异，不喜欢千篇一律的回忆。

小 H 认为差异的一种方式是尽量多的不同种类，另一种则是极差。小 H 认为第一种刻画缺少简洁之美，她定义一个序列 $a_{1\sim n}$ 的差异度为 $\max_{1\le i,j\le n}\{a_i-a_j\}$。

小 H 觉得只考虑全局的差异还是太千篇一律了，她决定了 $q$ 个追忆区间。记忆有酸甜苦辣，可每一次追忆应有相同的地位，为了简洁，小 H 决定将它们的差异度求和。

时光荏苒，回忆已经模糊不清，小 H 也与这些奇怪的问题愈行愈远。而我们和过去保持连接的方式就是记住，仅此而已。为了激励前行的你，小 H 将她尚还记住的回忆交予你，希望你能补上其余的回忆，**在最小化全局差异度的前提下，最小化观察区间的差异度之和**，从而帮小 H 减少追忆之旅的苦楚。

请你将观察区间差异度之和的最小值对 $20260722$ 取模告诉小 H。

## 输入格式

**本题有多组测试数据。** 输入的第一行一个正整数 $T$，表示测试数据组数，接下来输入每组测试数据。

对于每组数据，第一行输入 $2$ 个正整数 $n,q$ 表示序列的长度和追忆区间的个数，第二行 $n$ 个非负整数依次表示 $a_i$，若 $a_i=0$ 则表示小 H 不记得该位置。

接下来 $q$ 行每行两个正整数 $l_i,r_i$ 表示追忆区间。

## 输出格式

共 $T$ 行，每行一个非负整数，表示每组测试数据的答案对 $20260722$ 取模的结果。

## 输入输出样例 #1

### 输入 #1

```
3
3 1
20250301 0 20260722
1 3
6 3
1 0 4 5 0 4
1 2
2 5
6 6
7 4
514 514 0 1 0 114 514
1 3
1 3
3 5
4 7

```

### 输出 #1

```
10421
4
1026
```

## 说明/提示

对于第一组测试数据，一个可能的解是 $20250301,20260307,20260722$。

对于第二组测试数据，一个可能的解是 $1,1,4,5,1,4$。

对于全部测试用例，保证 $n,q\le 10^5,\sum n,\sum q \le 2\times 10^5,T\le 100,0\le a_i\le 10^9$。
