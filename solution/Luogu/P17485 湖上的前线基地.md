# P17485 湖上的前线基地 题解

## 题目大意

给定 $2^n$ 个节点的完全图，每个节点 $u,v$ 之间有一条权值为 $a_{u \operatorname{and} v}$ 的边，求最小生成树。

## 解法

### Sub 1、2

可以暴力建出 $O(4^n)$ 条边，然后跑最小生成树，复杂度为 $O(4^n\log 4^n)$。

### Sub 3

- 我们注意到其实不用建出所有的边，考虑 Kruskal 算法的过程，其实只是在找小的边，大的边不一定是需要的，那么可以针对这点进行优化。
- 我们把 $a_i$ 按照大小排序，然后从小到大扫这个数组。设 $a_i$ 原本的下标为 $x$，把 $x$ 作为中心，然后枚举补集 $M = (2^n - 1) \oplus x$ 的子集 $s$。
- 然后建一条 $x$ 到 $x \mathbin{|} s$ 的边，加入边集合。
- 对这个边集合跑最小生成树即可。候选边数为 $3^n$，复杂度为 $O(3^n\log 3^n)$。

### Sub 4、5

- 我们继续观察，可以注意到我们依然有很多的冗余边。
- 我们考虑一个距离 $x$ 很远的点 $u$ 的直达边，我们真的需要建这条边吗？如果我们可以不连这些边，通过某种转移能否达到这个点？
- 事实上，若 $x \subseteq u$，可以考虑从 $x$ 到 $u$ 的 1-bit 转移链。对链上的状态 $y$，都有 $a'_y \le a_x$，因为 $x$ 本身就是 $y$ 的一个子集。
更具体地，在只考虑边权不超过 $a_x$ 的候选边时，可以归纳证明：对于任意 $x\subseteq u$，$x$ 和 $u$ 连通。取 $u$ 中一个不属于 $x$ 的二进制位，令 $y$ 为删去这一位后的状态，则边 $(pos[y],u)$ 的权值为 $a'_y\le a_x$；而 $x$ 到 $y$、$pos[y]$ 到 $y$ 的连通性都可以归纳得到。因此，原本权值为 $a_x$ 的直达边，可以由这些候选边替代，不会改变 Kruskal 过程中的连通性。
- 利用子集和（高维前缀和）在 $O(n 2^n)$ 内预处理出每个状态 $x$ 的子集最小值 $a'_x$ 及其对应的来源节点 $pos[x]$。这里 $pos[x]$ 是一个子集，满足 $a_{pos[x]}=a'_x$。
- 枚举每个状态 $i$ 和它的每一个 0 位 $k$，建立一条从 $pos[i]$ 到 $i \mathbin{|} 2^k$ 的边，权值为 $a'_i$。这条边在原图中确实存在，因为 $pos[i]\subseteq i\subseteq i\mathbin{|}2^k$，两端按位与的结果就是 $pos[i]$。此时总边数精简为 $n \cdot 2^{n-1}$。
- 对这 $O(n 2^n)$ 条边跑 Kruskal 即可。总时间复杂度 $O(n 2^n \log(n 2^n))$，可顺利通过所有数据。

```cpp
# include <bits/stdc++.h>
using ll = long long;
const int MAX = 1e6 + 1e5;

int k, n;
ll ans;
int a[MAX], pos[MAX];
std::vector<std::tuple<int, int, int>> edge;
std::vector<std::pair<int, int>> eans;

struct DSU {
    int fa[MAX], siz[MAX];
    void init() {
        for (int i = 0; i < n; i++)
            fa[i] = i, siz[i] = 1;
    }
    int find(int x) { return fa[x] != x ? fa[x] = find(fa[x]) : x; }
    bool merge(int x, int y) {
        int fx = find(x), fy = find(y);
        if (fx == fy) return 0;
        if (siz[fx] < siz[fy]) std::swap(fx, fy);
        fa[fy] = fx;
        siz[fx] += siz[fy];
        return 1;
    }
} dsu;

int main() {
    std::cin.tie(0)->sync_with_stdio(0);

    std::cin >> n;
    k = n;
    {
        int res = 1;
        for (int i = 1; i <= n; i++)
            res *= 2;
        n = res;
    }
    dsu.init();
    for (int i = 0; i < n; i++)
        std::cin >> a[i], pos[i] = i;

    for (int i = 0; i < k; i++) {
        for (int st = 0; st < n; ++st) {
            if ((st >> i) & 1) {
                if (a[st] > a[st ^ (1 << i)]) {
                    int sub = st ^ (1 << i);
                    if (a[st] > a[sub]) {
                        a[st] = a[sub];
                        pos[st] = pos[sub];
                    }
                }
            }
        }
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < k; j++) {
            if (!((i >> j) & 1)) {
                edge.emplace_back(a[i], pos[i], i | (1 << j));
            }
        }
    }
    std::sort(edge.begin(), edge.end());
    for (int bs = n, i = 0; bs > 1 && i < edge.size(); i++) {
        auto [w, u, v] = edge[i];
        if (dsu.merge(u, v)) {
            ans += w;
            eans.emplace_back(u, v);
            bs--;
        }
    }
    std::cout << n - 1 << '\n';
    for (auto [u, v] : eans)
        std::cout << u << ' ' << v << '\n';
    std::cout << ans << '\n';
    return 0;
}
```
